# M0 — Feel prototype

**Критерий приёмки (SPEC §15):** 30 секунд тапания приятны без всякой прогрессии. Дальше M1 не начинаем, пока это не так.

## Как проверить
```bash
npm run dev          # http://localhost:5173, с телефона — Network-адрес из консоли
npm run dev -- --open "/?debug"
```
Открыть на телефоне (портрет), включить звук, тапать 30 секунд: медленно, быстро, по разным зонам.

## Чеклист
- [x] Один малыш-плейсхолдер (calico, стадия «Кроха»), пастельные эллипсы, части/якоря/хитбоксы как у будущего рига
- [x] Процедурная жизнь: дыхание, моргание (в т.ч. двойное), взгляд за пальцем + блуждание, пружинные уши и хвост с редкими подёргиваниями
- [x] Тап → squash & stretch от точки тапа, overshoot, голова отстаёт, «желе» при частых тапах
- [x] Реакции по зонам: голова (наклон), живот (подпрыг + рот), щёки (румянец), лапки (взмах), хвост (удивление)
- [x] Комбо: окно 450 мс, тиры 10/30/60/100, мягкое сползание; счётчик комбо с bounce, цвет по тиру
- [x] Частицы (пул ≤ 150): сердечки и искры веером, «+N» (pop → всплытие → fade)
- [x] Новый тир: кольцо-вспышка, арпеджио, радость малыша
- [x] Редкий тап 1/50: золотая звезда, ×5 сердечек, колокольчик
- [x] Звук: пентатоника C-D-E-G-A по номеру тапа в комбо, ±3% детюн, пул из 4 тембров, лимитер
- [x] Хаптика: light на тап (каждый 2-й при > 8 тап/с), medium на тир/редкий
- [x] Антиавтокликер: ≤ 12 тапов/с, лишние — только визуал
- [x] Настройки: звук, вибрация, «меньше движения» (без вспышек, меньше частиц)
- [x] Debug-панель `?debug`: скорость времени, настроение, +валюта, сброс комбо, хитбоксы/якоря, live-тюнинг всех juice-параметров, копирование диффа в JSON
- [x] Тесты sim (combo, лимитер, формулы, RNG, время), e2e-смоук со скриншотами
- [ ] **Плейтест на реальном телефоне (iOS + Android) — решение о приёмке за человеком**

## Что крутить, если «не то» (debug → Juice)
| Ощущение | Параметры |
|---|---|
| Тап «вялый» | `squash.amount` ↑, `squash.stiffness` ↑, `popup.overshoot` ↑ |
| Тап «дёрганый/резкий» | `squash.damping` ↑, `squash.directional` ↓ |
| Быстрое тапание «каша» | `squash.jellyPerTap` ↓, `particles.maxCount` ↓, `popup.lifeMs` ↓ |
| Мало праздника | `particles.*Count` ↑, `particles.speedMax` ↑, `comboRing.endRadius` ↑ |
| Малыш «мёртвый» в простое | `breathing.scaleY` ↑, `gaze.faceShift` ↑, `tail.swayAmp` ↑, `blink.maxInterval` ↓ |
| Звук утомляет | `audio.bopGain` ↓, `audio.bopDecayMs` ↓, `audio.pingPong` вкл, `audio.baseFreq` ↓ |
После тюнинга: «Скопировать JSON» → перенести значения в `src/content/juice.ts`.

## Известные ограничения M0
- Звук синтезируется (сэмплов нет), Howler появится вместе с ассетами.
- Хаптика в вебе — только `navigator.vibrate` (Android). iOS — через Capacitor в M5.
- Жесты «погладить» и «обнять» (§4.4) — в M1 вместе с care-циклом.
- Нет сохранения: прогресс M0 живёт до перезагрузки (сейв — M1).
