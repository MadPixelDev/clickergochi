# Принятые решения

Сюда записываются решения, которых нет в SPEC.md: дата, что решили, почему.

| Дата | Решение | Причина |
|---|---|---|
| 2026-11-14 | TypeScript закреплён на ~6.0 | typescript-eslint пока поддерживает TS < 6.1; TS 7 ставим, когда догонит линтер |
| 2026-11-14 | Howler.js и Capacitor пока не установлены | M0 без сэмплов (звук синтезируется Web Audio в `platform/audio.ts`), Capacitor нужен в M5. Добавим по мере надобности |
| 2026-11-14 | Мягкий сброс комбо: тап вне окна 450 мс не обнуляет комбо, а откатывает счётчик к началу текущего тира; без тапов 1.5 с — минус тир каждые 1.5 с | SPEC описывает только сползание по времени; так редкая пауза не наказывается (пиллар «без вины») |
| 2026-11-14 | Ноты комбо ходят вверх-вниз (ping-pong) по 2 октавам | Нет резкого прыжка вниз после 10-й ноты; переключается `juice.audio.pingPong` |
| 2026-11-14 | Juice описан дескрипторами (значение + диапазон), из них строятся zod-схема и слайдеры debug-панели | Одно место правды; переопределения из debug хранятся в localStorage только при `?debug` |
| 2026-11-14 | Расстояния juice — в логических юнитах сцены (колонка 1000), не в px | Одинаковый вид на всех экранах; «40 px» из §10 ≈ `risePx` 100 на телефоне |
| 2026-11-14 | Смещение глаз по SPEC (6% глаза) дополнено сдвигом лица `gaze.faceShift` и лёгким поворотом головы | Только 6% почти не видно на телефоне |
| 2026-11-14 | В M0 настроение фиксировано (`balance.mood.default` 0.8), крутится в debug | Потребностей ещё нет, а формула XP уже от него зависит |
| 2026-11-14 | Сердечки и XP хранятся дробными, на экране округляются; «+N» показывает 1 знак после запятой до 10 | Формула §9.2 даёт 1.1, 1.2… — без дробей бонус комбо не виден |
| 2026-11-14 | Тапы мимо малыша игнорируются (только взгляд) | Отклик «в пустоту» размывает обратную связь |
| 2026-11-14 | Debug-панель: подписи параметров — id из кода, без i18n | Dev-инструмент; заголовки и кнопки всё равно через i18n |
| 2026-11-14 | Playwright запускает Chromium с GPU (`--use-angle=metal`) | Без GPU headless рендерит WebGL ~5 fps, и скриншоты не показывают реальный отклик. На Linux CI флаги надо будет заменить |
