# CLAUDE.md — Fluffnest

Уютный 2D кликер-тамагочи: растим малыша-зверушку тапами и заботой, выращенные питомцы живут в домике-приюте.

## Перед любой задачей
- Прочитай `docs/SPEC.md` (геймдизайн + техника) и `docs/ART_PIPELINE.md` (правила ассетов).
- Посмотри `docs/DECISIONS.md` — уже принятые решения.
- Работаем по этапам `docs/SPEC.md` §15. Начинаем с **M0 — Feel prototype**. Не переходи к следующему этапу, пока не выполнен критерий приёмки текущего.

## Стек
TypeScript (strict) · Vite · PixiJS v8 · Preact (DOM-UI) · GSAP · Howler.js · zod · Capacitor · Vitest · Playwright.
Новые зависимости — только с обоснованием в `docs/DECISIONS.md`.

## Команды
- `npm run dev` — dev-сервер (debug-панель: `?debug`)
- `npm test` — юнит-тесты
- `npm run sim:balance` — прогон модели игрока, печать темпа роста и экономики
- `npm run e2e` — Playwright смоук + скриншоты
- `npm run build` — продакшен-сборка
- `npm run cap:sync` — синхронизация с iOS/Android

## Архитектурные правила
- `src/sim/` — чистая детерминированная логика: никаких импортов Pixi, DOM, Capacitor. Время только через `TimeService`, случайность только через seeded RNG.
- View не меняет состояние sim напрямую: ввод → `Command` → sim → события `EventBus` → view/juice.
- Все числа баланса — в `src/content/balance.ts`, все параметры отклика — в `src/content/juice.ts`. Магических чисел в коде нет.
- Контент (виды, мебель, комнаты, еда) — данные в `src/content/`, валидируются zod.
- Весь текст через i18n-ключи (RU + EN).
- Сохранение версионируется; любое изменение формата сейва = миграция + тест.

## Арт и плейсхолдеры
- Если ассета нет, рисуй процедурный плейсхолдер (пастельные эллипсы) с теми же частями, якорями и хитбоксами. Не блокируйся на арте.
- Питомцы вне interaction points используют только самодостаточные позы (SPEC §7.7). Позы «внутри предмета» — только через interaction points и сэндвич слоёв `back → pet → front` (SPEC §6.4).
- Тени на полу и все частицы — только кодом.

## Juice
- Каждое событие: первичный + вторичный отклик в пределах 100 мс (SPEC §10).
- Все эффекты уважают настройки «меньше движения», звук и хаптику.
- После изменений визуала/ощущений: Playwright-скриншот + короткое описание, что изменилось и какие параметры juice крутить.

## Definition of Done (для любой задачи)
- Тесты sim зелёные, новая логика sim покрыта тестами.
- Нет ошибок TypeScript и ESLint, нет `any`.
- Числа вынесены в content, тексты в i18n.
- Debug-панель позволяет проверить фичу (ускорение времени, выставление состояния).
- Решения, не описанные в SPEC, записаны в `docs/DECISIONS.md`.
